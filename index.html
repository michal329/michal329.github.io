LangChain HITL Research Agent

Human-in-the-loopLangGraph · Groq · Tavily · Streamlit

An autonomous research assistant that searches the web, groups what it finds, then pauses its own graph until a person approves the sources. Only then does it write the report. Reviewers can approve a subset, or reject with feedback that sends the agent back to search.

  • Search. The agent calls Tavily, and results are cached in a thread-safe source service.
  • Interrupt. The agent proposes sources through the approve tool, and middleware halts the LangGraph run.
  • Review board. A Streamlit panel lets the reviewer filter, check or uncheck sources, then approve (4/5) or reject with notes.
  • Resume. An Edit command rewrites the paused tool call so it carries only the approved sources. A Reject command returns the feedback to the model.
  • Clean service architecture (UI ↔ services ↔ tools) and a fully mocked pytest suite.
services/approval_service.py
def build_approval_command(selected_sources) -> Command:
    """Resume the paused graph with only the sources the human kept."""
    decision = {
        "type": "edit",
        "edited_action": {
            "name": "approve",
            "args": {"sources": format_approved_sources(selected_sources)},
        },
    }
    return Command(resume={"decisions": [decision]})


def build_rejection_command(feedback: str) -> Command:
    """Send the reviewer's notes back; the agent searches again."""
    return Command(resume={"decisions": [{"type": "reject", "message": feedback}]})

    def expand_nodes(node_list) -> list[str]:
    """Expand a Slurm node_list string into individual node names.

        expand_nodes("node-[01-03,07]")
        -> ['node-01', 'node-02', 'node-03', 'node-07']
    """
    if node_list in NULL_NODES:
        return []
    s = node_list.strip()
    if "[" not in s:
        return [p.strip() for p in s.split(",") if p.strip()]

    # split on commas that are NOT inside brackets, so "a-[1,2],b-[3]" works
    parts, depth, buf = [], 0, []
    for ch in s:
        if ch == "[":
            depth += 1
        elif ch == "]":
            depth -= 1
        if ch == "," and depth == 0:
            parts.append("".join(buf))
            buf = []
        else:
            buf.append(ch)
    parts.append("".join(buf))

    out = []
    for part in parts:
        m = _BRACKET.search(part.strip())
        if not m:
            out.append(part.strip())
            continue
        prefix, suffix = part[: m.start()], part[m.end():]
        for token in m.group(1).split(","):
            if "-" in token:
                lo_s, hi_s = token.split("-", 1)
                width = len(lo_s)  # preserve zero-padding, e.g. 01..09
                for n in range(int(lo_s), int(hi_s) + 1):
                    out.append(f"{prefix}{str(n).zfill(width)}{suffix}")
            else:
                out.append(f"{prefix}{token}{suffix}")
    return out

    Node counts are only right once compressed ranges are expanded. This is one of the normalisation steps every downstream analysis depends on.

    Real-time systems · game engine

    Kung Fu Chess

    Client–serverPython · pygame · websockets · Docker

    Chess with the turns removed. Both players move whenever they like, pieces take visible travel time, every arrival triggers a cooldown, and a piece can jump to dodge. An attacker that lands on an airborne piece is destroyed instead.

    You play White. Black moves on its own.
    1No turns. Click a white piece, then a highlighted square.
    2Travel time. Pieces fly square by square, so you can dodge.
    3Jump. Click a selected piece again. An attacker landing on it mid-air dies.
    4Win by capturing the king.

    A compact JavaScript port of the rules for the browser, using the project's real sprite art. The original engine is Python.

    • Stateless engine. GameEngine takes an explicit GameState on every call and keeps no game state on self, so the same engine runs offline tests and the server.
    • Registry-dispatched piece rules (dict[kind → rule_fn]) instead of if/elif chains. Value-object model: Position, Piece, Board.
    • Observer events. Rendering, move history and the server's network bridge all subscribe to the engine. None of them is referenced by it.
    • A deterministic test DSL (Board: / Commands: with wait <ms>) replays real-time scenarios exactly, without sleeping.
    • Multiplayer server. A websocket gateway, room manager, matchmaking, ratings, a SQLite user store and Docker Compose, plus a written design for scaling to 100M users (sharded game servers, NATS, Redis, PostgreSQL).
    • Synthesised from three independent implementations, keeping the strongest design decision from each.

# Landing on an airborne enemy: the jump wins, the attacker is removed.
defender = self._collision_resolver.airborne_defender(
    pending_move.to_pos, pending_move.piece.color, state.airborne)
if defender is not None:
    state.board.set(pending_move.from_pos, None)
    self._notify(AirborneCaptureEvent(defender=defender.piece,
                                      pos=defender.pos,

    return

    Nothing is reserved when a move is queued. Collisions are decided by what is actually at rest at the moment of arrival, which keeps the rules uniform and testable.
